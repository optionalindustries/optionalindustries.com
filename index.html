One person. A fleet of language models. 154 days to a live alpha.

Optional Industries is an independent game studio run by Nik — one person, and a standing fleet of language models that does the typing, the testing and the nightly work, never the deciding. The product is numbup, a 3D gacha auto-battler, in closed alpha on iOS and Android since 22 August.

Nik runs a payroll department for a living and had never written a line of C# before the first commit. numbup was built in the hours around that job.

Every figure on this page is measured from the repository when the page is built. Nobody types these numbers in by hand — including every one further down.

Not one line of numbup was typed by hand. It could not have been: the person directing the fleet had never written C#, and knew about as much SQL as a payroll job teaches. The fleet supplies the syntax. It does not supply the logic, the constraints or the refusals — every line shipped because someone read it, argued with it, or threw it out, and that part was never going to be automated.

The game itself contains no language model: the company is built with them, the product is not. And every 3D model, sound and texture in the game was made by a person: bought or licensed, never generated, credited wherever a license asks for it. Assets whose source could not be traced back to a person were replaced rather than kept. The full list of credits ships inside the game, under Settings → Credits.

This page has now had four wrong numbers. The first draft counted 37 where the repository held 22 — it had measured the machine the work happened on instead of the project. Three more followed, in the migration count, the alpha’s own date and the number of tests, and the sentences around them hid five further mistakes. No script caught any of it. Readers did, twice. That is the job.

How one person keeps up

Not the headcount. The line.

A studio of one keeps up by turning every repeated judgment into a tool that makes it the same way twice. The fleet runs overnight; the mornings are for deciding.

Bug reports filed inside the game open a thread in a channel within seconds. The chat word filter, the nightly cheat scan and the nightly review all run without anyone starting them.

A fleet that types fast is the easy half. The other half is what it is not allowed to do: 605 automated checks before a branch merges, a nightly review that reads the diff nobody else read, and every defect that still gets through written down with a number — 524 so far, 439 of them closed. None of that was built for elegance. It was built because the person reading the diffs could not catch a bad one by instinct. The interesting part was never the typing.
